1. 安装 MySQL
   SSH 登录服务器后执行：
   sudo apt update
   sudo apt install -y mysql-server
   安装过程不会弹出设置 root 密码的界面（Ubuntu 打包方式如此），root 走 auth_socket 插件，靠系统用户身份免密登录，这是正常的。

# 确认服务状态

sudo systemctl status mysql --no-pager

# 设为开机自启

sudo systemctl enable mysql
看到 active (running) 即安装成功。2. 基础安全（可选）

如果跳过，建议至少移除匿名用户：
sudo mysql -e "DELETE FROM mysql.user WHERE User=''; FLUSH PRIVILEGES;"

不要用 root 做远程连接。​ 新建业务账号。
sudo mysql
逐条执行（每次只粘一行，回车确认看到 Query OK 再执行下一条）：
CREATE DATABASE IF NOT EXISTS myapp DEFAULT CHARACTER SET utf8mb4 DEFAULT COLLATE utf8mb4_unicode_ci;
CREATE USER 'appuser'@'localhost' IDENTIFIED BY 'YourPasswordHere';
CREATE USER 'appuser'@'%' IDENTIFIED BY 'YourPasswordHere';
GRANT ALL PRIVILEGES ON myapp._ TO 'appuser'@'localhost';
GRANT ALL PRIVILEGES ON myapp._ TO 'appuser'@'%';
FLUSH PRIVILEGES;
SELECT user, host FROM mysql.user WHERE user='appuser';
预期输出：
+---------+-----------+
| user | host |
+---------+-----------+
| appuser | localhost |
| appuser | % |
+---------+-----------+
为什么要建两个？​ MySQL 用 用户名@来源IP 做身份匹配。localhost 和 127.0.0.1 是不同来源，DBeaver 偶尔解析成 localhost，留两个避免 Access denied。
退出：
EXIT;
本地验证登录：
mysql -u appuser -p -h 127.0.0.1 myapp
能进入 mysql> 提示符 = 用户没问题。4. 验证 MySQL 安装

报错
原因
解决

Could not load trustJKS keystore
DBeaver 想用 SSL 但 JKS 文件损坏
SSL 页全关 + JDBC URL 加 useSSL=false

Public Key Retrieval is not allowed
MySQL 8 默认 caching_sha2_password，关了 SSL 需要允许公钥获取
JDBC URL 加 allowPublicKeyRetrieval=true

Access denied for 'appuser'@'localhost'
用户不存在或 DBeaver 走了 localhost 解析
Host 写 127.0.0.1 + 确认 appuser@localhost 用户存在

bind: Address already in use
本地 3306 被占用
SSH 隧道换本地端口（如 13306），DBeaver 连 13306

粘 SQL 没生效
多行粘贴引号被截断
每次只粘一行执行 7. 生产环境补充建议
当前配置适合开发环境。生产环境额外需要：
改用 SSH 密钥登录（不用密码）
appuser 权限收紧到最小（SELECT, INSERT, UPDATE, DELETE 而非 ALL）
如果走方案 B（公网直连），需改 bind-address = 0.0.0.0 + 云安全组限源 IP + require_secure_transport=ON
定期备份：mysqldump -u root myapp > backup.sql

# 安装

sudo apt update && sudo apt install -y mysql-server && sudo systemctl enable mysql

# 建用户（进 mysql 后逐条执行）

CREATE DATABASE IF NOT EXISTS myapp DEFAULT CHARACTER SET utf8mb4 DEFAULT COLLATE utf8mb4_unicode_ci;
CREATE USER 'appuser'@'localhost' IDENTIFIED BY 'YourPasswordHere';
CREATE USER 'appuser'@'%' IDENTIFIED BY 'YourPasswordHere';
GRANT ALL PRIVILEGES ON myapp._ TO 'appuser'@'localhost';
GRANT ALL PRIVILEGES ON myapp._ TO 'appuser'@'%';
FLUSH PRIVILEGES;

# 验证

mysql -u appuser -p -h 127.0.0.1 myapp
